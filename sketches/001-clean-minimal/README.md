## Variant: Clean Minimal

### Design stance
简洁、留白、内容优先。灵感来自 Linear/Notion 的现代 SaaS 设计语言。

### Key choices
- **Layout**: 左侧导航栏 (220px) + 右侧内容区，大量留白
- **Typography**: Inter 字体，大标题 (28px)，清晰的层级
- **Color**: 浅色主题，蓝色主色调 (#2563eb)，卡片化布局
- **Interaction**: 卡片 hover 效果，表格行高亮

### Trade-offs
- Strong at: 视觉舒适、信息层级清晰、新用户友好
- Weak at: 信息密度低、需要更多滚动、专业用户可能觉得"空"

### Best for
- 追求简洁美观的个人用户
- 移动端优先的场景
