## Variant: Dense Professional

### Design stance
高效、信息密集、工具感。灵感来自 VS Code/Total Commander 的专业工具设计。

### Key choices
- **Layout**: 顶部工具栏 + 左侧窄侧栏 (200px) + 内容区 + 底部状态栏
- **Typography**: 系统字体，紧凑的行高，小字号 (13px)
- **Color**: 深色主题，蓝灰配色，高对比度
- **Interaction**: 紧凑的列表视图，面板化布局，状态栏实时信息

### Trade-offs
- Strong at: 信息密度高、一屏展示更多内容、专业感强
- Weak at: 视觉疲劳、新用户学习成本高、移动端适配难

### Best for
- 追求效率的高级用户
- 桌面端为主的场景
- 需要同时查看多种信息的场景
